# Breezerland Perfumes — Static Website

This repository contains the static website for Breezerland — a premium fragrance manufacturer and exporter based in Rajkot, Gujarat.

Contents:
- `index.html` — landing page
- `styles.css` — primary stylesheet
- `script.js` — lightweight interactions and animations
- `logo1.png`, `FNL FNl.jpg.jpeg` — provided brand assets

Local preview:
1. Open `index.html` in your browser (double-click or use a local static server).

Deploy to Vercel (recommended):
- Option A (web): Connect this GitHub repository to Vercel via the Vercel dashboard and deploy.
- Option B (CLI): Install Vercel CLI (`npm i -g vercel`), run `vercel login`, then `vercel` from this folder.

Notes:
- The contact form has a placeholder front-end handler. Integrate a serverless function or form provider to accept submissions.
